About Job Application Tracker

Job Application Tracker is a Flask and MySQL based web application that helps users manage and track job applications efficiently.

Features

  • Add New Applications
  • View All Applications
  • Update Application Status
  • Delete Applications
  • Dashboard Analytics
  • Track Applied Dates

Technologies Used

Python Flask MySQL HTML CSS

Developer

Developed by Zaker Raza to demonstrate backend development skills using Flask and MySQL.
